# Security policy

Only the latest release is supported.

For a security problem, use a private GitHub security advisory after the repository is public. Do not include private note content unless it is required to reproduce the issue, and remove unrelated private information first.

Document PDF Exporter can read user-selected Vault files, user-selected external files, and local files embedded by selected notes. It can write a PDF to a path selected by the user.

The plugin does not use telemetry, remote code, runtime downloads, shell commands, Python, or an external browser process.
