# Changelog

## 1.0.0

- Build one ordered PDF from notes, PDFs, and images.
- Select and reorder note headings directly in the source tree.
- Preserve custom PDF page order, including reverse ranges.
- Keep cover pages off by default.
- Imported PDF page labels show page numbers without repeating the source title.
- Markdown table `<br>` markers create real line breaks inside the same cell.
- Multi-line table cells wrap and size cleanly during PDF layout.
- Render PDFs inside Obsidian with a sandboxed Electron print window.
- Keep exported documents free of local paths, hashes, and technical appendices.
